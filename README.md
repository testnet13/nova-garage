# NOVA Garage

Prototype V1 exécutable d'un SaaS pour garages : tableau de bord, demandes clients, workflow atelier, rendez-vous, devis, assistant conversationnel, paramètres et aperçu du widget web.

## Démarrage

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Important

La conversation IA actuelle est une simulation locale pour la démonstration. La version commerciale devra ajouter : authentification, base de données multi-tenant, API IA côté serveur, notifications SMS/email, stockage sécurisé, journalisation, sauvegardes et conformité RGPD.

Ne jamais placer de clés API ou de données clients réelles dans le dépôt.
